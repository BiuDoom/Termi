## 行为边界

- 远端没有 `posix-rename@openssh.com` 扩展时，同名覆盖明确失败并保留原件；新文件仍可上传。不会降级成先截断原文件的实现。
- 替换上传拒绝符号链接和非普通文件；若无法保留已有文件的属主或权限，也拒绝发布。替换创建新 inode，不承诺保留 SFTP v3 未提供的 ACL、扩展属性或硬链接关系。
- 网络已经断开时，无法保证删除远端隐藏的 `.termi-upload-*.part` 临时文件；原目标保持完整。服务端重新连通后可清理这些临时文件。
- 目标变化检测使用 SFTP v3 可提供的属性，不是服务端比较并交换锁；不能阻止另一个写入者在最后校验后、原子重命名前更新同一路径。原子发布防止的是上传失败/取消造成半文件。
- 同名 CSV 分组无法表达父路径时明确拒绝歧义，避免随机绑定。CSV 本身不导出分组的身份、跳板及其他配置；完整迁移仍使用加密导出。
- 修改运行中的转发路线会停止旧路线，新路线需明确启动；只改自动启用属性不会误换正在运行的路线。
